segmnt hosts and streams your course videos. Your viewers watch on **your** site,
from **your** domain. Every playback link is signed, so a copied link does not
work anywhere else.

This site is for developers who build with segmnt: agencies, course platforms
and training companies. These guides are in **English**. The Arabic guides are
on the older site at [test-docs.segmnt.cloud](https://test-docs.segmnt.cloud/ar/).

## Start here

- [Accounts, projects, API keys and domains](/accounts-and-projects) —
  sign in (SSO only), create a project, make an API key, verify a domain.
- [Direct upload](/direct-upload) — send a video straight to storage with
  pre-signed URLs. Examples in Node.js, Python and PHP/Laravel.
- [Reports and video review](/reports-and-review) — file a viewer report, and
  know what a hold or a remove does to playback.
- [Moderation and held videos](/moderation) — how the automatic check works,
  why a video is held for review, and how a held video is released.

## Status of this site

Everything here runs on **TEST**. A production release starts only after the
board approves it.

We only document features that are released. These pages come later, when the
feature ships:

- Playback tokens and the player — when signed playback ships.
- Embed codes: iframe and JavaScript — when the player ships.
- Webhooks and the encoding pipeline — when the encode pipeline ships.
